# Isaac Ndahura — Personal Website

A single-page, editorial personal archive built with Astro static output, GSAP motion, and Matter.js bookshelf interaction. The PRD and DESIGN.md are the behavioral and visual authorities. This branch is the first implementation slice; copy, work inventory, imagery, contact destination, font pairing and exact visual tokens remain review items.

## Development

- Node.js `>=22.22.0` (Astro 7 requirement)
- `npm ci`
- `npm run dev`
- `npm run check`
- `npm test`
- `npm run build`

The site is static; Vercel previews are for review only. Production aliases, public launch, domains and DNS remain separately approval-gated.
